# Workshop 02, Exercises

Suggested hands-on follow-ups to the session. Each one starts from a concept
in the deck and ends with something you can run.

## Exercise 1, describe a simulator (~10 min)

1. Pick one concept you teach at the instrument (dwell time, pinhole size,
   numerical aperture, alignment, anything).
2. Write a one-paragraph prompt for an AI coding assistant: what the learner
   should be able to change, what they should see change, and the one formula
   or rule that must stay physically correct.
3. Ask for a single self-contained HTML file with one slider and one canvas.
   Open it in a browser and check the physics against a reference before you
   show it to anyone.

**Stretch:** add a "predict first" prompt to the page so the learner commits
to a guess before moving the control.

## Exercise 2, one record, one place (~10 min)

1. List the places where one of your SOPs currently lives (shared drive,
   email, printed copy, booking system notes).
2. Decide which copy is the reference and what the others should become
   (a link, or deleted).
3. Write the two sentences that tell a new user where the reference is and
   who owns it.

**Stretch:** draft the Workspace Studio flow (trigger, understand, act,
review) that would keep that reference current.

## Exercise 3, inspect the evidence (~10 min)

1. Open the cell-counter slide, run the segmentation at the default threshold
   and count the merged objects by eye.
2. Change the threshold and minimum size until the overlay separates them,
   then note what the count did.
3. Write down one check you would require before trusting an automated count
   on real data.
