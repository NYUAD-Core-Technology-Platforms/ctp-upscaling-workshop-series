# Cheat sheet

One page to keep next to you for the first week. Up: [[index]]

## Markdown in two minutes

| You type | You get |
|---|---|
| `# Title`, `## Section` | Headings |
| `**bold**`, `*italic*` | **bold**, *italic* |
| `- item` | A bullet list |
| `1. step` | A numbered list |
| `- [ ] task` | A checkbox (`Ctrl+L` ticks it) |
| `[[Note name]]` | A link to another note |
| `[[Note name\|label]]` | A link with your own label |
| `[text](https://example.org)` | A web link |
| `` `code` `` | Inline code |
| `> text` | A quote |
| `key: value` lines between two `---` lines at the very top | Properties (structured fields) |

## Obsidian in two minutes

| To | Windows and Linux | macOS |
|---|---|---|
| Create a note | `Ctrl+N` | `Cmd+N` |
| Open a note by name | `Ctrl+O` | `Cmd+O` |
| Run any command | `Ctrl+P` | `Cmd+P` |
| Search all notes | `Ctrl+Shift+F` | `Cmd+Shift+F` |
| Switch between reading and editing | `Ctrl+E` | `Cmd+E` |
| Open the graph | `Ctrl+G` | `Cmd+G` |
| Open settings | `Ctrl+,` | `Cmd+,` |
| Copy a note as a starting point | Right-click it → *Make a copy* | same |

- **A vault is a folder.** Every note is a `.md` file you can open in any text editor.
- **Links:** type `[[` to link a note. Backlinks (the notes that link here) are in the right
  sidebar.
- **Rename safely:** **Settings** → *Files and links* → *Automatically update internal links*: on.
- **A faded link** means the note doesn't exist yet. Click it to create it.
- **Properties** at the top of a note (status, owner, dates) make notes easy to filter, for you
  and for AI tools.

## Five habits

1. If it's not in the vault, it didn't happen.
2. Before closing a chat, have the AI write down the decision and the current state.
3. One fact, one home: link to it, don't copy it.
4. Commit after every session, or let a plugin do it.
5. Start every new chat from the files, not from memory.

## Guardrails

No passwords or personal data · private repositories · approved AI tools for institutional data ·
agents propose, you approve · what the AI reads is data, not instructions · review the diff.
